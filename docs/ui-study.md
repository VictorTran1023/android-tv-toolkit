# 设计研究：Apple tvOS 风格桌面

> **状态：设计稿，未在电视上实施。** 不接管 HOME、不替换 `cyberui`、不改任何系统设置。
> 先确认视觉、焦点和代价，再决定要不要做成可安装的普通 App，最后才讨论 HOME 接管。

## 为什么是 tvOS

这台电视的瓶颈是内存与渲染（3.83 GB / 4 核 / 1080p60），而现有首页常年占着 21% CPU + 300 MB。tvOS 的思路刚好相反：

- **一屏一件事**：没有多排推荐流、没有频道页，只有时间、正在看的内容、直播/输入源和 Dock。
- **大留白 + 大焦点**：3 米外靠尺寸和描边辨认，而不是靠密集小字。
- **背景是内容**：壁纸/剧照铺满，界面元素浮在上面，不用大面积毛玻璃。
- **遥控器优先**：方向键只在「内容区 ↔ Dock」之间移动，没有隐藏手势。

## 设计原则

1. **一屏**：首页就是全部，不做横向分页、不做二级首页。
2. **内容优先**：继续观看 / 直播 / 输入源 > 应用图标 > 设置。
3. **少而大**：一屏最多 1 个主卡 + 2 个侧卡 + 7 个 Dock 图标。
4. **真实数据**：没有继续观看就显示空状态，不编造进度和节目名。
5. **不做模糊**：Android 11 + 弱 GPU，毛玻璃用半透明纯色代替。
6. **可回退**：先做普通 App，不接管 HOME；接管是后话。

## 焦点模型

三个区：**内容区（主卡 + 侧卡）**、**Dock**、**顶部胶囊（不可聚焦）**。

| 起点 | 按键 | 去向 |
| --- | --- | --- |
| 主卡 | ← / → | 侧卡（直播 → 输入源） |
| 主卡 | ↓ | Dock（记住上次的图标） |
| 侧卡 | ← | 主卡 |
| 侧卡 | ↓ | Dock |
| Dock | ← / → | 图标间移动（循环） |
| Dock | ↑ | 回到上次停留的内容卡 |
| 任意 | OK | 打开 / 播放 / 切换输入源 |
| 任意 | Back | 回 Dock；Dock 上再按不退出桌面 |

- **默认焦点**：主卡（继续观看），没有内容时落在 Dock 第一个图标。
- **焦点记忆**：从 Dock 回内容区时，回到上次停留的卡；从内容区下 Dock 时，回到上次图标。
- **不丢按键**：主卡切换动画期间缓存 1 次方向键，动画结束立即执行。
- **焦点可见性**：白描边 + 缩放 + 外投影，三种里至少两种；不靠颜色区分。
- **顶部胶囊不可聚焦**：它们是状态，不是按钮；设置入口放 Dock。

## 内容与数据

| 卡片 | 有数据 | 空状态 |
| --- | --- | --- |
| 继续观看 | 剧照 + 标题 + 集数 + 进度 + 播放键 | 「还没有观看记录」+ 最近使用 |
| 直播电视 | 频道名 + 当前节目 + LIVE | 「未检测到直播源」 |
| 输入源 | HDMI 列表 + 连接状态 | 「未检测到输入」 |
| Dock | 真实应用图标 + 名称 | 不足 5 个时左对齐，不补假图标 |

- 应用图标用 `PackageManager` 的真实图标（96×96），缺图标才用首字 + 固定底色。
- 剧照用 16:9 或 2:1；没有剧照时用低饱和渐变 + 标题，不伪造海报。
- 进度只来自真实播放记录；拿不到就不显示进度条。
- 天气/时间复用 HUD 的数据源；没有数据时显示 `—`。

## 动效与性能

| 项 | 目标 | 手段 |
| --- | --- | --- |
| 冷启动首帧 | < 1.2 s | `windowBackground` 纯色/品牌图；图标异步加载 |
| 常驻内存 | < 90 MB | 图标 96×96 + `LruCache` 8 MB；背景预烘焙 |
| 空闲 CPU | < 3% | 无轮询、无动画常驻 |
| 焦点动画 | 60 fps | 只改 `scale`/`translation`/`alpha` |
| 背景 | 不每帧重绘 | 预烘焙 480×270 Bitmap 放大；渐变/噪点一次生成 |
| 主卡切换 | 不掉帧 | 只动 2 层（卡片 + 文字），不整屏模糊 |

- **禁用**：`RenderEffect` 高斯模糊、全屏 `blur`、大面积 `box-shadow`、每帧 `RadialGradient`。
- **减少动态**：系统 `animator_duration_scale=0` 时直接切，不做补间。
- **不做视差**：电视 GPU 弱，背景移动不超过 4 px。

## 与横向分页方案的区别

| 项 | 横向分页（旧思路） | tvOS 风格（本方案） |
| --- | --- | --- |
| 信息架构 | 多页、每页一类内容 | 单页，内容分层 |
| 导航 | 左右切页 + 页内焦点 | 只有内容区 ↔ Dock |
| 视觉 | 斜切、轨道、每页换色 | 连续背景、统一表面、系统蓝 |
| 动效 | 整页横移 | 焦点缩放 + 背景淡入 |
| 实现 | ViewPager2 + PageTransformer | 单 Activity + 自定义 View/焦点容器 |

## 风险与回滚

| 风险 | 概率 | 影响 | 应对 |
| --- | --- | --- | --- |
| 厂商 PMS 拦截安装 | 中 | 装不上 | 按 `brands.md` 选 UI 安装通道 |
| HOME 接管后首帧闪原桌面 | 中 | 观感 | 只做普通 App 时不存在；接管前先观察 |
| 遥控焦点丢失 | 中 | 不可用 | 焦点状态机 + 单次按键测试 |
| 内存吃紧被 LMK 杀 | 低 | 回桌面重载 | 常驻 < 90 MB，图标缓存上限 8 MB |
| HUD 与桌面状态重复 | 中 | 视觉噪音 | 桌面常驻时 HUD 隐藏，或桌面不画状态 |

**回滚**（只装普通 App 时）：

```bash
adb uninstall com.victor.tvos
```

接管 HOME 的回滚见 `brands.md` 与设备记录；本设计不默认接管。

## 明确不做

- ❌ 不替换/停用 `cyberui`、`com.tcl.settings`、systemui、遥控服务
- ❌ 不改画质、HDR、局域调光、音效、信号源、Wi-Fi、账号
- ❌ 不做 root / 解锁 / 刷机
- ❌ 不复制 Apple 的影片、字体、图标或航拍素材；只参考布局语言
- ❌ 不在第一版做跨 App 播放进度抓取（先做「最近使用」）
